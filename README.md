🎨 ColorPalette Generator

 A lightweight and simple color palette generator — create beautiful, harmonious color sets and gradients for your web designs or apps in seconds.


---

🌈 Overview

ColorPalette Generator helps designers and developers generate visually appealing color palettes quickly.
You can:

Generate random or logically related colors (like gradients or harmonic tones).

View color values in HEX format.

Copy colors with one click.

Save or reuse palettes later.

Use it directly in design projects or front-end development.



---

🚀 Features

Clean, fast, and responsive UI.

Auto-generate complete color palettes (e.g., 5 related colors).

Create and preview linear gradients ready for CSS.

Copy any color code or gradient directly.

(Optional) Save and share your palettes easily.

---

🧩 Usage Examples

Copy a HEX Color

Click on the copy icon next to a color to get something like:

#34A853

Generate a Gradient (CSS-ready)

The app produces gradient code like:

background: linear-gradient(90deg, #34A853 0%, #2A73D6 100%);
